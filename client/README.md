# PlaceRec - Recording Studio Website

Современный веб-сайт студии звукозаписи.

## Технологии

- **React 18** - библиотека для построения пользовательского интерфейса
- **TypeScript** - типизированный JavaScript для безопасности типов
- **Vite** - быстрый сборщик проектов
- Pocket base - backend из коробки на go

## Структура проекта

```
src/
├── components/          # Переиспользуемые компоненты
├── pages/              # Страницы приложения
│   ├── Home.tsx        # Главная страница
├── assets/
│   └── const.ts        # Константы приложения
├── App.tsx             # Корневой компонент
├── main.tsx            # Точка входа
├── App.css             # Глобальные стили
└── index.css           # Базовые стили

public/
└── portfolio/          # Статические файлы портфолио

```

## Установка и запуск

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev
```

Установить pb под нужную ОС.
Настроить pb, импортировать коллекции из pb/pb_schema.json
создать в корне .env, значения по умолчанию:

```bash
VITE_PB_BASE_URL=http://127.0.0.1:8090
```
